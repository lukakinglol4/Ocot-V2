# Ocot Client v2 Enhanced 🎨

A powerful, feature-rich proxy client with smooth animations and beautiful UI.

## Features

- 🌐 Proxy Management
- 🎮 Games List
- 📝 Notes
- 🧮 Calculator
- 💻 Console
- 🎭 Cloaking Tools
- 🌊 History Flood
- 🔄 CORS Proxy
- 🔍 Pocket Browser
- 📜 Scripts
- 🔖 Bookmarklets
- ⚙️ Settings

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development: `npm run dev`
4. Build for production: `npm run build`
