# Before Commit Checklist

Please ensure you complete the following steps before committing:

1. **Check for errors** - Review your code for any syntax errors, TypeScript errors, or runtime issues
2. **Run the build command** - Execute `npm run build` to ensure the application builds successfully
3. **Change the latest version** - Update the version number in `package.json`
4. **Make a new release** - Create and publish a new release with the updated version

Make sure all steps are completed before pushing your changes.
